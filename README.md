# Harini Shree G — Personal Portfolio Website

A responsive, zero-dependency portfolio website built from Harini Shree G's resume and profile portrait.

## Project Structure

- `index.html` — Semantic HTML5 portfolio sections (Hero, About, Skills, Projects, Education, NPTEL Certificates, Contact) plus Project Details & Resume Preview modals.
- `styles.css` — Light & Dark mode styling, responsive grid layouts, print-ready resume sheet, and subtle scroll animations.
- `script.js` — Theme toggle (`localStorage`), category project filtering, project architecture modal, resume preview/print modal, clipboard copy toast, and `mailto:` contact composer.
- `assets/profile.jpg` — Profile portrait.
- `assets/resume-preview.png` — Original uploaded resume image (viewable inside the Resume modal).

## Preview Locally

You can open `index.html` directly in a browser, or serve it with Python:

```bash
python -m http.server 8080
```
